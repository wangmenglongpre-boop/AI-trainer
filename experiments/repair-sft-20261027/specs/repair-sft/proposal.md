# 函数修复 SFT 学习实验

目标：熟悉预训练模型的监督微调，验证任务假设、数据处理、参数更新和独立评测，而不是只追求训练 loss。

沿用学习计划 W5–W6 的任务：Python 简单函数修复。基座为 Qwen/Qwen2.5-Coder-1.5B-Instruct，单卡 RTX 4090。当前字符 GPT 可用于继续预训练机制练习，但其字符词表、128 字符上下文和弱指令能力不适合承担此代码 SFT 的效果评估。

假设：经过人工核验的修复样例可以提升同分布未见任务的单次测试通过率。基座已有能力时 few-shot 可能已足够；微调收益须超过原模型基线，且不能明显损害保留任务能力。

当前已交付后训练环境、两条教学样例，以及 authored-v1 的 30/5/5 条 train/dev/test 链路数据。20 道来源题先分组再生成 bug；参考答案通过 133 个显式期望测试，所有 bug 有公开失败证据，真实 tokenizer 检查通过。数据由 AI 辅助自编并自动核验，尚未获得独立人工审阅，不作为正式效果基准；GPU SFT 未执行。
